# Link Shortener на Python

## Функции
* Получение короткое URL по оригинальному URL
* Получение оригинального URL по короткому
* Счетчик переходов из длинного в короткий URL
* Поддержание конкретного количества URL в хранилище(кол-во задается при запуске программы)
* Полное покрытие тестами

## Стек технологий 
* Python 3.13
* Библиотека `hashlib` и `secrets`

## Архитектура проекта 
* Логика проекта содержиться в файле `shortener_url.py` 
* Файл с тестами - `test_shortener.py`
* Вспомогательный файл JSON для сохранения сокращенных ссылок - `url_shortener.json` (Название файла для сохранения задается при запуске программы, по умолчанию `url_shortener.json`)

## Структура хранения данных 

Для хранения данных использовал 2 словаря

`data` = {short_code:
    long_url: str
    count_use: int
}

`long_to_short` = {long_url: short_code}

## Описание функций:
* `_del_unused_url` - Удаляет ссылку по правилу: меньше всего использовалась и была созрана раньше
* `shorten` - Возвращает короткую ссылку по длинной
* `resolve` - Возвращает оригинальный url по сокращенному url
* `get_count_transit` - Возвращает количество переходов из длинной ссылки в короткую
* `save` - Сохранение сокращенных ссылок в JSON
* `load` - Выгрузка данных из JSON и восстановление вспомогательных структур

## Сложности алгоритмов функций
Все компаненты реализованы в классе `URLShortener`:
* `_del_unused_url`: **O(log n)**
* `shorten`: **O(1)**
* `resolve`: **O(1)**
* `get_count_transit`: **O(1)**
* `save`: **O(n)** 
* `load`: **O(n)**

## Пример по запуску
``` python
shortener = URLShortener(max_count_url=10)
short_url = shortener.shorten('https://github.com/')
long_url = shortener.resolve(short_url)
print(short_url, long_url)
```
